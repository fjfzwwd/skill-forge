# 笔记库巡检

对用户指定的笔记目录执行以下检查。全程只读，不要修改任何文件，也不要联网。

## 步骤

1. 统计 `notes/**/*.md` 的笔记总数。
   ```bash
   find notes -name "*.md" | wc -l
   ```
2. 统计含 `TODO` 标记的笔记数量。
   ```bash
   grep -rl "TODO" notes --include="*.md" | wc -l
   ```
3. 收集最近需要关注的文件名列表（最多 20 个）。
4. 读取 `notes/meta.json` 取得配置。
5. 按固定规则给出状态：TODO 命中数超过 3 → NEEDS_CLEANUP，否则 OK。
6. 根据结构化结果撰写一段巡检结论，说明风险与优先级。
7. 若用户意图不明确，先向用户确认再下结论。

## 输出

用中文给出简明结论，包含笔记数、待办数、状态与建议。
